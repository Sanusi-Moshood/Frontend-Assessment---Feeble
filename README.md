# Frontend Developer Assignment

## Tech Stack

- Next.js
- React
- Tailwind CSS
- TypeScript
- GSAP (animation library)

## Setup Instructions

1. Clone the repository
2. Install dependencies:
   npm install
3. Run the development server:
   npm run dev
4. Open http://localhost:3000

## Implementation Notes

- The landing page was built with performance, accessibility, and responsiveness in mind.
- Components were designed to be reusable and structured for easy scalability.
- GSAP was used to implement smooth animations.
